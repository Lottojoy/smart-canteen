# 🍽️ Smart Canteen - ระบบแนะนำโรงอาหารอัจฉริยะ (กลุ่ม SekSolo)

โครงงานนี้คือการพัฒนาระบบ AI เพื่อคาดการณ์ความหนาแน่นและจำนวนโต๊ะว่างของ "โรงอาหารหอพักนิสิต (โรงส้ม) มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตกำแพงแสน" โดยใช้ Machine Learning (Random Forest) เรียนรู้จากความสัมพันธ์ของ ช่วงเวลา วันในสัปดาห์ และสภาพอากาศ (อุณหภูมิ, ปริมาณน้ำฝน) เพื่อช่วยแนะนำช่วงเวลาที่เหมาะสมในการเข้าใช้บริการ ลดความแออัดและการรอคอยในช่วงพักเที่ยง

## 📖 คู่มือการใช้งานสำหรับผู้ใช้ (How to Use)
เมื่อเข้าสู่เว็บไซต์ทดสอบ อาจารย์และผู้ใช้งานสามารถทดสอบระบบได้ดังนี้:
1. ไปที่แท็บ **"🎯 ระบบแนะนำเวลา"**
2. เลือก **วัน** และ **เวลา** ที่ต้องการจะไปรับประทานอาหาร
3. ระบุ **สภาพอากาศปัจจุบัน** (เช่น น้ำท่วม, ปกติ) และระบุ **อุณหภูมิ/ปริมาณน้ำฝน**
4. กดปุ่ม **"🚀 ประมวลผลด้วย AI"**
5. ระบบจะแสดงกราฟแนวโน้ม และคำนวณจำนวนโต๊ะว่างที่คาดการณ์ พร้อมให้คำแนะนำ (🟢 ไปได้เลย, 🟡 เริ่มแน่น, 🔴 ควรหลีกเลี่ยง)
*หมายเหตุ: สามารถดูข้อมูลดิบที่ใช้เทรนโมเดลได้ที่แท็บ "ข้อมูลจากการสำรวจจริง" และดูค่าความแม่นยำ (RMSE) ได้ที่แท็บ "ประสิทธิภาพโมเดล AI"*

## 📂 โครงสร้างและคำอธิบายโค้ด (Project Structure)
โปรเจกต์นี้ประกอบด้วยไฟล์หลักๆ ดังนี้:

* **`appCanteenfinal.py`** : โค้ดหลักสำหรับแสดงผลหน้าเว็บแอปพลิเคชัน (พัฒนาด้วย Streamlit) ทำหน้าที่รับค่าจากผู้ใช้ ส่งให้โมเดลทำนาย และแสดงผลลัพธ์
* **`train.py`** : สคริปต์สำหรับฝึกสอน (Train) โมเดล แบ่งชุดข้อมูล (Train/Test) ประเมินผล และบันทึกโมเดลที่ดีที่สุดออกมาเป็นไฟล์ `.pkl`
* **`canteen_model.pkl`** : ข้อมูล AI ที่พร้อมสำหรับทำนายผล
* **`canteen_common.py`** : ไฟล์รวบรวมฟังก์ชันและตัวแปรส่วนกลาง (เช่น การโหลดข้อมูล, การสร้างฟีเจอร์) เพื่อลดความซ้ำซ้อนของโค้ดระหว่างตอนเทรนและตอนใช้งานจริงบนเว็บ
* **`Canteen_Data.xlsx`** : ฐานข้อมูลดิบ (Dataset) ที่ได้จากการลงพื้นที่เก็บข้อมูลจริงเป็นเวลา 12 วัน
* **`requirements.txt`** : ไฟล์ระบุรายชื่อไลบรารีที่จำเป็นในการรันโปรเจกต์ (เช่น streamlit, pandas, scikit-learn)
* **`images/`** : โฟลเดอร์สำหรับจัดเก็บรูปภาพประกอบที่แสดงในหน้าเว็บไซต์
